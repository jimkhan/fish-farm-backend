# fish-farm-backend

Generated **backend** code (NestJS modular monolith, Clean Architecture, TypeORM Data Mapper +
PostgreSQL) for the Fish Farm Management System (FMS).

The source of truth is the spec hub: **../fish-farm-context-files/** (start at `INDEX.md`).
This repo implements `../fish-farm-context-files/contracts/openapi.yaml`.

Do not edit code by hand to fix a problem — change the spec and regenerate. See `.cursorrules`
for the execution rules, invariants, and guardrails. The coding constitution is
`../fish-farm-context-files/CLAUDE.md`.
